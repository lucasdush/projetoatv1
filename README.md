# ATV2


Objetivo do Sistema O sistema é uma ferramenta para abertura e controle de chamados técnicos , permitindo registrar problemas de Suporte ou Infraestrutura e acompanhar o status de resolução.

Principais Funcionalidades

- Identificação Obrigatória : Agora, todo chamado exige o preenchimento do Nome e Telefone do solicitante, além dos dados do cliente (CNPJ/CPF).
- Inteligência de Prioridade : Ao selecionar o tipo de problema, o sistema define automaticamente se o chamado é Leve, Médio ou Grave , ajudando na organização do atendimento.
